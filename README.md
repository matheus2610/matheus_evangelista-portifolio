- `index.html` — página inicial
- `exp.html` — experiência profissional
- `projeto.html` — projetos
- `cursos.html` — certificações e formação
- `style.css` — estilos e responsividade
- `script.js` — menu mobile, carrossel e ano do rodapé

## Como executar

1. Extraia a pasta.
2. Abra `index.html` no navegador.

Não há build, Node.js ou framework obrigatório. O site funciona como HTML/CSS/JS estático.
